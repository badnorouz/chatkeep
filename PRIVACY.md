# Chatkeep privacy statement (draft)

- Chatkeep runs entirely on your computer. It has no accounts, no analytics and no servers of its own.
- It reads Claude Code / Claude desktop app chat files that are already on your computer, copies them into the backup folder you choose, and opens claude.ai export files you give it.
- The only network access is downloading the files listed in your own claude.ai export e-mail, when you press import. Those links point to claude.ai.
- Settings are stored in a small config file in your user data folder. Uninstalling the app does not delete your backups.
- **Transfer** only creates the files you ask for (a ZIP you download, or a `.chatkeep/` folder and a marked block in `AGENTS.md` / `GEMINI.md` in a project folder you choose). It never reads or changes another app's own data. Common passwords and API keys are hidden by default, but review the files before sharing them.
